# ML Python Summer 2026

Летний учебный репозиторий по Python, machine learning и ML engineering.

## Цель

Сформировать прочный инженерный фундамент для дальнейшего развития в сторону ML-инженерии.

## Структура

- `module_01_python_engineering` — Python, тесты, Git и инженерные основы
- `module_02_math_for_ml` — NumPy, математика и статистика для ML
- `module_03_data_analysis_and_sql` — pandas, SQL и EDA
- `module_04_classical_machine_learning` — классическое машинное обучение
- `module_05_deep_learning_pytorch` — deep learning и PyTorch
- `module_06_mlops_and_deployment` — API, Docker, MLflow и MLOps
- `portfolio_projects` — законченные портфельные проекты
- `exercise_notes` — заметки, привязанные к конкретным упражнениям

Порядок обучения, контрольные точки и стратегия подготовки к трудоустройству описаны в [LEARNING_ROADMAP.md](LEARNING_ROADMAP.md).
