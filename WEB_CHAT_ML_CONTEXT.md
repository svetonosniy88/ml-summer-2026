## Текущий практический код

В локальном проекте находится такой скрипт:

```python
from sklearn.datasets import load_iris
import matplotlib.pyplot as plt

iris = load_iris(as_frame=True)

plt.scatter(
    iris.frame["petal length (cm)"],
    iris.frame["petal width (cm)"],
    c=iris.target,
)

plt.xlabel("Длина лепестка, см")
plt.ylabel("Ширина лепестка, см")
plt.title("Iris: лепестки и виды")
plt.show()
```

График уже строится. Точка остановки — не написание нового кода, а понимание того, как строки таблицы превращаются в точки и цвета.

## Текущая задача

Нужно разобрать первую диаграмму Iris:

- одна строка датасета соответствует одной точке;
- `iris.frame["petal length (cm)"]` задаёт координату по оси `x`;
- `iris.frame["petal width (cm)"]` задаёт координату по оси `y`;
- `c=iris.target` передаёт числовую метку класса для выбора цвета;
- `iris.target_names` связывает метки `0`, `1`, `2` с названиями видов;
- строки с индексами `0`, `50`, `100` удобно использовать как по одному представителю каждого класса.

Критерий завершения: пользователь без подсказки объясняет, как конкретная строка Iris превращается в точку с определёнными координатами и цветом, а затем своими словами описывает, что график показывает о разделимости видов.

Не переходи к train/test-разделению или модели, пока этот критерий не выполнен.
